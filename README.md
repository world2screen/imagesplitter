# installing
press "Code" -> "Download ZIP" then extract the zipped file to a folder.  
run "pip install pillow" in cmd, then run main.py with python (from cmd or otherwise)  
# usage
use 13:3 aspect ratio for guns and 72x24 resolution for namemc  
guns: goto links, click "add custom link" set file to 1U1 then repeat with 1U2 and so on  
namemc: set skin to 3U9 wait ~15 secs refresh your profile, then go onto 3U8, repeat  
(if the skins aren't showing up after setting your skin just check again in a minute or two)
